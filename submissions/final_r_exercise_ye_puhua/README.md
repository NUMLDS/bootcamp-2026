# NY School Poverty and Test Performance

This project studies the relationship between poverty and test performance in
New York public schools.

## Folder contents

- `data/raw/`: original datasets
- `data/processed/`: cleaned and transformed datasets
- `scripts/1_clean.R`: cleans the data
- `scripts/2_transform.R`: creates variables and merges the data
- `scripts/3_analyze.R`: creates summary tables
- `scripts/4_plot.R`: creates plots
- `capstone_report.Rmd`: project report
- `capstone_report.html`: rendered report
- `run_all.R`: runs all scripts in order

## Run the project

Open `capstone.Rproj`, run `source("run_all.R")`, and then knit
`capstone_report.Rmd`.
