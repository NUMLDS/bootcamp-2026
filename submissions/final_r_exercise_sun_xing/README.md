# Final R Exercise

This project analyzes the relationship between poverty and test performance in New York public schools.

## Project Structure

- `data/raw/`: original data files
- `data/processed/`: cleaned and processed data
- `scripts/1_clean.R`: data cleaning
- `scripts/2_transform.R`: data transformation and merging
- `scripts/3_analyze.R`: summary tables and analysis
- `scripts/4_plot.R`: data visualization
- `report.Rmd`: analysis report
- `run_all.R`: runs all scripts in order
