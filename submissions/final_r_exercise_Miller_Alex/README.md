# Capstone Project: Poverty and School Performance

## Overview
This project examines the relationship between county-level poverty and
student test performance using merged school and demographic data.

## Data
- `data/processed/merged.csv` — school-level merged dataset
- `data/processed/poverty_group_trend.csv` — poverty group trends over time

## Analysis
See `analysis/plots.R` for the main visualizations:
- FRL access vs. math performance
- Test scores by poverty group
- Poverty gap trends over time
