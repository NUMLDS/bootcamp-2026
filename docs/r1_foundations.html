Logical Operators

  • These are R’s core logical operators
  • == for “is equal”
  • ! for “is not”
  • & for “and”
  • | for “or”
  • < for “less than”
  • > for “greater than”
  • A statement with logical operators returns TRUE or FALSE

Example: Logical Operators

5 > 4
[1] TRUE
(5 > 4) & (4 < 5)
[1] TRUE
(5 > 4) | (4 < 5)
[1] TRUE
!(4 > 5)
[1] TRUE

More on Vectors

  • When something is vectorized, it means that multiple values are processed at once instead of going through a loop

  • Missing values are stored as NA and different functions will handle them differently

vec <- c(1, 8, NA, 7, 3)
mean(vec)
[1] NA
mean(vec, na.rm=TRUE)
[1] 4.75
sum(is.na(vec)) # the total number of NA values
[1] 1

Lists

  • Lists are like vectors, but more flexible
  • Lists are heterogeneous (vs homogeneous vectors): they can store single elements, vectors, or even other lists
  • Lists let you keep multi-dimensional or ragged data in R
  • Index a list element with double brackets: [[1]]
    • Single brackets return the element still wrapped in a list

Example: Lists

my_list <- list(42, "Hello world!",  c(1, 2, 3, 4, 5))
my_list[[2]]
[1] "Hello world!"
my_list[2]
[[1]]
[1] "Hello world!"
class(my_list[[2]])
[1] "character"
class(my_list[2])
[1] "list"

Factors

  • Factors are a special vector type useful for categorical variables
  • Factors have a set number of levels (typically auto-detected)
  • For categorical variables with a natural order, use ordered factors
  • Create factors with factor(), which takes a levels argument
fac <- factor(c("red", "yellow", "green", "green", "green"))
class(fac)
[1] "factor"
levels(fac)
[1] "green"  "red"    "yellow"

Data Frames

  • Data frames are R’s core data structure: a list of named vectors of equal length
  • Data frames are heterogeneous — each column can be a different data type
    • Columns are variables
    • Rows are observations
  • Build one with data.frame() or cbind()/rbind()
  • Extract specific values using df[row, col] and specific columns using df$var or df["var"]

Example 1: Data Frames

df <- data.frame(
  name = c("Ava", "Bob", "Cam"),
  age = c(25, 30, 35),
  active = c(TRUE, FALSE, TRUE)
)
df
  name age active
1  Ava  25   TRUE
2  Bob  30  FALSE
3  Cam  35   TRUE
department <- c("Sales", "Marketing", "Engineering")
df <- cbind(df, department)
df
  name age active  department
1  Ava  25   TRUE       Sales
2  Bob  30  FALSE   Marketing
3  Cam  35   TRUE Engineering
