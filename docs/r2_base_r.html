Subsetting

  • Subsetting means working with just part of a data frame
  • Two common approaches:
    • Index it directly: df[df$continent == "Asia", ]
    • Use subset(): subset(df, subset = continent == "Asia")

Sorting

  • sort() reorders values
    • Ascending by default
    • Use decreasing = TRUE to flip
  • order() gives you the index positions in sorted order
    • Useful for reordering a whole data frame
  • Rule of thumb
    • Use sort() for vectors and order() for data frames

Adding & Removing Columns

  • Add a new column two ways:
df$newvar <- newvar
df <- cbind(df, newvar)
  • Remove a column just as easily:
df$newvar <- NULL

Creating New Columns

  • Two common approaches:
    • Simple case: one function does the job
      • Just assign its result to a new column
    • Conditional case: no single function fits
      • Create an empty column, and then fill it in based on a condition

Aggregating

  • We often want summary statistics by group
  • aggregate() does this: aggregate(y ~ x, data = df, FUN = mean) gives the mean of y for each group in x
